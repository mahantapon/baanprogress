# BaanProgress — หน้าเว็บแนะนำระบบ

หน้าเว็บแนะนำ (landing page) ของระบบรายงานความคืบหน้าโครงการก่อสร้าง
สำหรับส่งให้บริษัทรับสร้างบ้านที่สนใจ

ภาพประกอบทั้งหมดเป็นภาพจากระบบจริง โดยใช้ข้อมูลตัวอย่าง ไม่ใช่ข้อมูลลูกค้ารายใด

ตัวอย่างระบบให้ลองใช้: https://mahantapon.github.io/construction-report-demo/
